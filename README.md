# Owned Causality: Constraint Closure, Basin Steering, and the Emergence of Agency from Chemistry

PIATRA Institute paper proposing a non-circular primitive for owned causality: a single mathematical object $\mathfrak{O}_T(\Omega)$ assembled from chemical reaction-network theory, chemical organisation theory, autocatalysis and RAF, closure to efficient causation, closure of constraints, autopoiesis, semantic closure, Markov-blanket inference, basin dynamics, and circular causality across levels. The right-hand side contains no "I" or "self"; both appear later as a compressed model of recurrent high-$\mathfrak{O}_T$ history.

- `paper/PAPER.md` — the paper. Build with `bash paper/scripts/build-paper.sh` (requires pandoc + xelatex).
- `simulation/` — reproduces every numeric claim. Run with `cd simulation && uv run run_all.py`.
- `chat.md` — the original draft from which the paper was developed.
